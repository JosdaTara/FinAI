# FinAI — Asistente Inteligente de Finanzas Personales

Proyecto de aula — Nuevas Tecnologías.

Aplicación web para gestionar ingresos y gastos personales con un asistente inteligente basado en IA (Google Gemini) que analiza los datos financieros del usuario y genera recomendaciones.

## Stack

- **Frontend:** React + Vite + Chart.js
- **Backend:** Node.js + Express
- **Base de datos:** Firebase Firestore + Firebase Auth
- **IA:** Google Gemini API

## Estructura

```
FinAI/
├── backend/    # API Express (datos, estadísticas, asistente IA)
└── frontend/   # Interfaz web React
```
